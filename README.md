# Mercatto Caixa — instalador para Windows

[Baixar o instalador (Windows 10/11, 64 bits)](https://github.com/contatomateusslopes-ux/mercatto-caixa/raw/main/Mercatto-Caixa-Setup.exe) — versão 1.0.0

1. Baixe e abra o arquivo.
2. Se aparecer "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**.
3. Abra pelo ícone **Mercatto Caixa** na área de trabalho. Na primeira vez é preciso internet e login; depois o caixa funciona offline.
